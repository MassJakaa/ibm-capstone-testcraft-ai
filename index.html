Latar Belakang & Problem Statement

Dalam siklus rekayasa perangkat lunak modern, pembuatan test suite manual memakan waktu hingga 35-40% dari total waktu pengembangan, sering kali mengabaikan skenario batas ekstrem (boundary values) dan celah keamanan input.

Solusi: AI Agent dengan 3-Layer Prompt

Dikembangkan menggunakan IBM Bob melalui metodologi Vibe Coding dan Context Engineering, agen ini membedah kode sumber atau user story menjadi unit test komprehensif, matriks partisi ekivalensi, dan spesifikasi BDD Gherkin otomatis.

Arsitektur Prompt 3-Layer (IBM Bob)

LAYER 1

Role & Context (Peran & Konteks)

Bob berbicara ke siapa dan dalam konteks apa?

"Anda adalah Senior QA Automation Architect dan Software Testing Specialist. Tugas Anda adalah menganalisis kode sumber, spesifikasi fungsional, atau user story dan menghasilkan test suite otomatis kelas enterprise berstandar industri."
LAYER 2

Task & Requirements (Tugas & Kebutuhan Fitur)

Apa yang harus benar-benar dibangun?

"Bangun web application 'TestCraft AI' dengan: (1) Input multi-format (Code, Story, API), (2) Generator Test Suite lengkap (PyTest, Jest, JUnit, BDD Gherkin), (3) Tabel Matriks Partisi Ekivalensi & Nilai Batas, (4) Detektor Edge Case & Celah Keamanan, (5) Interactive Test Runner Simulator dengan visual progress, log latency, dan metrik cakupan cabang."
LAYER 3

Constraints & Output (Batasan & Standar Luaran)

Bagaimana hasil akhirnya harus terlihat dan berfungsi?

"Arsitektur frontend modular: 3 file terpisah (index.html, style.css, app.js). Gunakan Tailwind CSS (CDN) + Vanilla JS tanpa dependensi bundler/framework tambahan. Palet warna IBM Carbon (dark slate, cobalt blue #0f62fe, emerald, amber). Zero console errors, responsif mobile-to-desktop, clean code dengan komentar terstruktur."
